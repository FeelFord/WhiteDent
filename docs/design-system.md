# WhiteDent: дизайн-система этапа 1

Токены находятся в `src/app/globals.css` (`@theme inline` Tailwind CSS 4 и CSS-переменные).

| Токен Tailwind | Цвет | Назначение |
| --- | --- | --- |
| `ink` | `#171D21` | Hero, контакты, основной текст |
| `slate` | `#3B484F` | Дополнительный тёмный |
| `gold` | `#C7AB83` | Кнопки, акценты на тёмном фоне |
| `paper` | `#F6F3EE` | Светлые информационные секции |
| `pearl` | `#EAE7E1` | Текст на тёмном фоне |

Типографика: системный sans-serif и Georgia для курсивных акцентов. Внешние шрифты не загружаются. Заголовки масштабируются через clamp. Контейнер до 1280 px, адаптивные поля, брейкпоинты 360/768/1024/1200 px.

Компоненты: `.button`, `.text-link`, `.eyebrow`, `.status-tag`, `.section`; Header, Footer и Reveal. Кнопки и ссылки имеют hover и видимый keyboard focus. Неактивная запись — настоящий disabled button. FAQ использует нативные details/summary. Мобильная навигация — раскрываемый список, не модальный диалог: Tab остаётся в обычном потоке, Escape закрывает меню и возвращает фокус.

В этапе 3 затемнены вспомогательные подписи и номера на светлых фонах; для мелкого текста на slate-фоне используется pearl. Основные брендовые цвета сохранены. Семантическая демо-плашка — именованный aside; название ссылки на главную берётся из видимого текста. Страницы, интерактивные состояния и контраст проверяются axe без исключения правил или элементов.

Motion анимирует небольшое смещение секций однократно. Содержимое видно без анимации и JavaScript. При reduced motion движение отключается, плавная прокрутка заменяется обычной.

Оригинальный WD-логотип: `public/brand/whitedent-logo.png`, исходные 300 × 300 px. Общий компонент `Brand` выводит исходный PNG напрямую (`unoptimized`), с масштабированием только для отображения и сохранением соотношения 1:1. Фильтры, перекрашивание, обрезка, скругление и изменение фона не применяются. Файл также используется напрямую как favicon. Декоративные композиции не являются логотипом или фотографиями клиники.

# WhiteDent на GitHub Pages

## Архитектура

Исходники остаются в `main` репозитория `FeelFord/WhiteDent`. GitHub Pages получает только статические файлы из `out/` через отдельную ветку `gh-pages`. Это демонстрационный проект; собственный домен, CNAME и официальный сайт клиники не изменяются.

Ожидаемый стандартный адрес после включения Pages и завершения GitHub deployment: `https://feelford.github.io/WhiteDent/`. Один push в gh-pages не используется как доказательство доступности сайта: адрес нужно проверить после публикации.

GitHub Pages поддерживает статический экспорт без Node-сервера. Префикс `/WhiteDent` задаётся во время сборки; Next Link учитывает его для страниц, а `src/config/site.ts` — для оригинального PNG и favicon. Внутренние страницы экспортируются с завершающим слешем и index.html для прямого открытия и обновления браузера.

## Сборка и проверка

```bash
npm ci
npm run build:pages
npm run test:pages
```

`npm run build:pages` включает статический экспорт только для этой команды. Обычные `npm run dev` и `npm run build` сохраняют серверный режим Next.js. Переменные режима — WHITEDENT_STATIC_EXPORT и NEXT_PUBLIC_BASE_PATH, это параметры сборки без секретов.

Для просмотра статического результата: `npm run preview:pages`, порт 3200, путь `/WhiteDent/`. Скрипт просмотра отдаёт реальные файлы, редиректы каталогов и фирменную 404; серверных обработчиков формы нет.

Статические тесты проверяют все 12 страниц на ширинах 320/375/768/1024/1440, ресурсы и логотип, переходы Next Link, фильтр, FAQ, мобильное меню, форму без отправки, отсутствие хранения данных, no-JS, noindex, .nojekyll, отсутствие CNAME, 404 и автоматическую доступность.

Проверено при подготовке этой версии: `npm run build:pages` — PASS, `npm run test:pages` — 12/12 (22.3 с), обычный `npm run build` и `npm run typecheck` — PASS, `npm run test:e2e` — 47/47 (51.1 с). Экспорт содержит 86 файлов, 15 HTML, около 1.78 МБ; 85 текстовых файлов проверены на распространённые форматы секретов, совпадений не найдено. Symlink и CNAME отсутствуют, SHA-256 PNG совпадает с оригиналом.

## Публикация

Перед публикацией сохраните проверенные исходники в коммит. Выполните `npm run deploy:pages`. Он:

1. Проверяет репозиторий, ветку main и чистое рабочее дерево.
2. Проверяет HTML noindex, префикс ресурсов, .nojekyll, отсутствие CNAME и исходный SHA-256 логотипа.
3. Создаёт Git tree статической сборки через отдельный временный индекс без переключения рабочей ветки и без worktree.
4. Отправляет один deployment-коммит в gh-pages обычным fast-forward push. Существующая gh-pages принимается только с маркером нашего демопроекта.
5. Сверяет SHA удалённой ветки. Временный индекс удаляется. Исходники, .git, .next, node_modules, кэши, ключи и настройки облачной среды не загружаются.

Разрешение на публикацию этой демонстрации получено. Команда фактически отправляет файлы в GitHub; для новых проектов и другого назначения требуется отдельное согласование.

Если Pages ещё не включён, откройте Settings → Pages в репозитории и выберите:

- Source: **Deploy from a branch**.
- Branch: **gh-pages**.
- Folder: **/(root)**.
- Нажмите **Save**; Custom domain оставьте пустым.

Интерфейс: `https://github.com/FeelFord/WhiteDent/settings/pages`. Это настройка хостинга текущего проекта, а не регистрация собственного домена. После успешного Pages build/deployment откройте стандартный URL и проверьте страницы.

Программная настройка через API возможна только при доступе к api.github.com и достаточных GitHub-правах. В текущей среде API-запрос был заблокирован сетевой политикой. Требования доступа к api.github.com и feelford.github.io сохранены в черновике настроек среды; Git-доступ к репозиторию работает. Для GitHub Pages не нужен VERCEL_TOKEN. Состояние сети и Pages следует повторно проверять после изменений.

## Деморежим и индексация

Все HTML, включая 404, содержат noindex/nofollow. Sitemap пустой. GitHub Pages не поддерживает настройку нашего X-Robots-Tag через next.config: поэтому в экспортном режиме эта настройка отключена, а запрет индексации задаётся в HTML каждой страницы. Файл robots.txt в подпапке `/WhiteDent/` не управляет robots для корня feelford.github.io. Не меняйте чужую корневую страницу ради robots.

Контакты и WhatsApp не активированы, профиль врача демонстрационный, медицинские тексты требуют проверки, цены не опубликованы. Форма выполняет только локальную валидацию и не отправляет данные; без JavaScript она отключена. Нет аналитики, CRM, базы данных или стороннего виджета карты. Все эти свойства сохраняются в статическом экспорте.

## Будущий собственный домен

Подключается отдельно после разрешения пользователя. Если сайт будет находиться в корне нового домена, задайте NEXT_PUBLIC_BASE_PATH пустым при сборке и измените настройки Pages/DNS только в рамках согласованной задачи. Повторите проверки путей, noindex, контактов и обработки данных; демонстрационный статус не снимается автоматически.

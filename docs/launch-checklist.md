# WhiteDent: подготовка к демонстрации и официальному запуску

Публикация и Git push не разрешены. Эта памятка описывает будущие действия, не выполняет их и не означает согласование запуска.

## Выполнено локально

- [x] Многостраничная демонстрационная версия, отдельные конфигурации контента.
- [x] Контакты, услуги и профили с явными статусами; нет фиктивных рейтингов и отзывов.
- [x] Форма без серверной отправки и сохранения полей.
- [x] Запрет индексации через metadata, HTTP-заголовок и robots.txt; пустой sitemap.
- [x] Проверки адаптивности, клавиатуры, браузерных сценариев и автоматический аудит axe.
- [x] Оригинальный логотип не подменён; неподтверждённые телефон и WhatsApp не активированы.

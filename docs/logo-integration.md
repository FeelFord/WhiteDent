## Источник и сохранность

Оригинал найден в `FeelFord/WhiteDent`, ветка `main`, коммит `a53f778` (`Add files via upload`), файл `dfcc5e.png`. Выполнен read-only fetch и локальное fast-forward обновление main; до обновления проверено, что удалённый коммит добавляет только этот PNG. Локальный код сайта и изменения README сохранены.

Файл перемещён в `public/brand/whitedent-logo.png`. Изображение не перерисовывалось, не перекодировалось, не обрезалось и не изменялось. Сохранены буквы WD, цвета, исходный фон/прозрачность, PNG-метаданные и пропорции.

- Git blob до и после перемещения: `33b0444fd6234b6772658bffcec95bdb9c315c15`.
- SHA-256 до и после перемещения: `6fb759068bdc3016356aedab774851150498bb6f01eb9c7dd9533333d3857de5`.
- Путь на диске: `/workspace/WhiteDent/public/brand/whitedent-logo.png`.
- Путь приложения: `/brand/whitedent-logo.png`.

Общий компонент Brand подключён в Header и Footer. Next Image используется с `unoptimized`: браузер получает оригинальный файл. Меняются только размеры отображения с соотношением 1:1; фильтров, масок, обрезки, скругления и перекрашивания нет. Favicon использует тот же PNG напрямую, отдельные производные изображения не создавались.

## Просмотр и ограничения

Production-сервер текущего сеанса запущен на порту 3000. Для интерактивного просмотра нужно доступное перенаправление порта среды; повторный запуск описан в README. Серверные процессы не гарантированно сохраняются после перезапуска среды.

Контакты, расписание, услуги, врачи и другие медицинские сведения не стали подтверждёнными из-за получения логотипа. Деморежим, запрет индексации и отключение реальной записи сохранены. Lighthouse после интеграции не запускался: прежние оценки относятся к сборке до добавления логотипа. На момент проверок интеграции commit ещё не выполнялся. Push, публикация и изменения PUBG не выполнялись.

## Просмотр

Production-сервер текущего сеанса запущен на порту 3000. Процессы не гарантированно сохраняются после перезапуска среды. Для запуска из `/workspace/WhiteDent`: `npm ci`, `npm run build`, `npm run start`; для разработки — `npm run dev`. Не запускайте два сервера на одном порту. При занятом 3000 используйте `npm run dev -- --port 3002`.

Скриншоты текущей версии находятся в `.cache/screenshots/stage-2-services.png`, `stage-2-contacts-mobile.png`, `stage-2-doctors.png`. Каталог игнорируется Git.

## Ограничения

Оригинальный WD-логотип отсутствует и не заменён. Реальных профилей врачей нет: показан один явно демонстрационный образец без вымышленных ФИО, стажа и образования. Медицинские тексты, услуги, адрес, график и контакты требуют проверки клиникой. Телефонные и WhatsApp-ссылки отключены. Форма работает только локально; серверной отправки, CRM и базы данных нет. Privacy — черновик. Canonical не задан без утверждённого домена. Внешние сведения повторно не проверялись.

Работа остаётся локально в `main`. Commit, push и публикация не выполнялись. PUBG не затрагивался.

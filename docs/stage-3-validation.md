# Этап 3: доступность, метаданные и производительность

Исторический отчёт до получения оригинального логотипа. Его последующая интеграция и актуальные проверки описаны в `logo-integration.md`. Lighthouse-оценки ниже относятся к сборке до интеграции логотипа.

Проверена локальная production-сборка WhiteDent. Работа остаётся в ветке `main`; commit, push и публикация не выполнялись.

## Изменения

- Повышен контраст вспомогательного текста и нумерации на светлых фонах, подписей на градиентах и мелкого текста на slate-фоне. Основная палитра сохранена.
- У ссылки названия клиники убрано несогласованное aria-label: доступное имя теперь определяется видимым текстом.
- Демонстрационная плашка оформлена как именованный aside, содержимое находится в семантических областях страницы.
- Добавлен `src/lib/seo.ts`: уникальные title, description, Open Graph и Twitter-метаданные на всех страницах, единый запрет индексации.
- Добавлены axe-проверки и команда `npm run test:quality`; зависимость axe установлена только для разработки.
- Добавлен `docs/launch-checklist.md` с отдельными условиями демонстрационного и официального запуска.

Lighthouse 13.6.0, локальный Chromium, мобильная симуляция, стандартное замедление CPU 4×. Проверена окончательная сборка после тестов. Значения — отдельные лабораторные измерения в общей облачной среде, не полевые Core Web Vitals и не показатели реального хостинга.

Единственная проваленная SEO-проверка в обоих отчётах — `is-crawlable`: демоверсия намеренно закрыта от индексации. Запрет не снимался ради оценки. Исходный замер главной до исправлений: Performance 99, Accessibility 96, Best Practices 100, SEO 63; небольшое изменение Performance между отдельными прогонами не интерпретируется как улучшение или ухудшение скорости.

Отчёты: `.cache/audits/lighthouse-home.report.html`, `.cache/audits/lighthouse-home.report.json`, `.cache/audits/lighthouse-contacts.report.html`, `.cache/audits/lighthouse-contacts.report.json`. Исходный замер: `.cache/audits/lighthouse-before.json`. Эти локальные артефакты игнорируются Git.

Для повторения после запуска production-сервера (отдельная установка инструмента вне проекта):

```bash
cd /workspace/WhiteDent
npm install --prefix /tmp/whitedent-audit --cache /tmp/whitedent-audit-cache --save-exact lighthouse@13.6.0 --no-fund --no-audit
mkdir -p .cache/audits
CHROME_PATH=/usr/bin/chromium /tmp/whitedent-audit/node_modules/.bin/lighthouse http://127.0.0.1:3000/ --chrome-flags='--headless --no-sandbox' --only-categories=performance,accessibility,best-practices,seo --output=json --output=html --output-path=.cache/audits/lighthouse-home --quiet
```

Для контактов замените URL-путь на `/contacts` и имя отчёта на `lighthouse-contacts`. На другой машине укажите установленный Chromium. Не выполняйте замеры одновременно с нагрузочными браузерными тестами. Lighthouse не входит в production-зависимости.

## Просмотр и оставшиеся условия

Сервер текущего сеанса работает на порту 3000. Для интерактивного просмотра требуется доступное перенаправление порта; инструкции повторного запуска — в README. Финальный скриншот: `.cache/screenshots/stage-3-home.png`.

Оригинальный WD-логотип не предоставлен и не заменён. Контакты, услуги, медицинские тексты, врачи и материалы клиники ожидают подтверждения; форма остаётся локальной, запись отключена. Политика — юридически не согласованный черновик. Safari, Firefox, реальные устройства, скринридеры и реальный HTTPS-хостинг не проверялись. Перед запуском нужен отдельный контентный и юридический review, проверка целевых устройств и явное разрешение на push и публикацию. PUBG не затрагивался.
